Молекулярная динамика: потенциал Леннарда-Джонса
1. Назначение программы

Программа моделирует движение N взаимодействующих частиц в двумерной области с периодическими граничными условиями. Взаимодействие между частицами описывается потенциалом Леннарда-Джонса. Численное 
интегрирование уравнений движения выполняется по алгоритму Верле.

2. Структура проекта

Папка проекта содержит:

    src/ — исходный код на C (main_verle.c, mt19937-64.c, mt64.h)

    scripts/ — вспомогательные скрипты (animate.py для визуализации)

    run_all.sh — главный скрипт для компиляции и запуска

    lab1.md — текст лабораторной работы

3. Требования к системе

Программа работает в Linux (Ubuntu, Debian, Fedora, Arch). Для работы необходимы:

    Компилятор gcc

    Библиотека math (подключается флагом -lm)

    Python 3 с пакетами numpy и matplotlib

Установка Python-пакетов:
pip3 install numpy matplotlib

4. Подготовка к запуску

Перед первым запуском нужно дать права на выполнение скрипта:
chmod +x run_all.sh

5. Запуск программы

Запуск производится командой:
./run_all.sh

После запуска появляется меню выбора состояния:

2 - ГАЗ (регулярная решётка)
3 - ЖИДКОСТЬ (малая)
4 - ЖИДКОСТЬ (большая)
5 - ТВЕРДОЕ ТЕЛО (квадратная решётка)
6 - ТВЕРДОЕ ТЕЛО (треугольная решётка)

Пользователь вводит номер (1-6) и нажимает Enter.
6. Что происходит после выбора

Скрипт выполняет следующие действия автоматически:

    Компилирует C-код с нужным макросом (например, -DSTATE_GAS_REGULAR)

    Запускает симуляцию

    Выводит в консоль значения кинетической, потенциальной и полной энергии на каждом сохранённом шаге

    Открывает окно с анимацией движения частиц (скрипт animate.py)

    Ждёт нажатия Enter, после чего закрывает окно и завершает работу

7. Параметры симуляции для каждого режима

Режим 1 — ГАЗ (случайные положения): N = 10, L = 30.0, скорость = 0.15, позиции случайные, решётка отсутствует.

Режим 2 — ГАЗ (регулярная решётка): N = 10, L = 12.0, скорость = 0.15, позиции регулярные, решётка квадратная.

Режим 3 — ЖИДКОСТЬ (малая): N = 36, L = 12.0, скорость = 0.06, позиции регулярные, решётка квадратная.

Режим 4 — ЖИДКОСТЬ (большая): N = 100, L = 20.0, скорость = 0.06, позиции регулярные, решётка квадратная.

Режим 5 — ТВЁРДОЕ ТЕЛО (квадратная решётка): N = 25, L = 12.0, скорость = 0.0008, позиции регулярные, решётка квадратная.

Режим 6 — ТВЁРДОЕ ТЕЛО (треугольная решётка): N = 25, L = 12.0, скорость = 0.0008, позиции регулярные, решётка треугольная.

Общие параметры для всех режимов: шаг по времени h = 0.0005, количество шагов STEPS = 10000, сохранение данных каждые SAVE_EVERY = 100 шагов, радиус обрезания потенциала rcut = 3.5 * sigma.

8. Вывод программы

В консоль выводятся строки вида:
Шаг X: Ek = значение, Ep = значение, E = значение
    где:
    Ek — кинетическая энергия (всегда положительная)

    Ep — потенциальная энергия (отрицательная в жидком и твёрдом состояниях)

    E = Ek + Ep — полная энергия (должна сохраняться)

9. Анимация

Окно анимации показывает движение частиц.

    Границы поля фиксированы по первому кадру.

    Синие точки — частицы.

    В заголовке окна отображаются номер шага и количество частиц.

    Задержка между кадрами составляет 50 миллисекунд (20 кадров в секунду).

10. Принцип работы алгоритма Верле

Алгоритм Верле (Velocity Verlet) работает следующим образом:

    По текущим координатам вычисляются силы, действующие на каждую частицу: a(t) = F(t) / m

    Координаты обновляются по формуле: r(t+h) = r(t) + v(t)·h + 0.5·a(t)·h²

    По новым координатам вычисляются силы для следующего шага: a(t+h) = F(t+h) / m

    Скорости обновляются по формуле: v(t+h) = v(t) + 0.5·(a(t) + a(t+h))·h

Преимущество алгоритма — хорошее сохранение энергии при достаточно малом шаге h.
11. Периодические граничные условия

Реализованы через функцию min_image(dx), которая преобразует разность координат между двумя частицами так, чтобы она лежала в диапазоне [-L/2, L/2]. Это имитирует бесконечную систему: частица, вылетевшая за правую границу, взаимодействует с частицей у левой границы.

13. Почему программа не работает на Windows

Программа написана для Linux, так как использует:

    bash-скрипты (run_all.sh)

    POSIX-пути с прямым слешем (/)

    Системные вызовы system() и mkdir

Для запуска на Windows необходимо установить WSL (Windows Subsystem for Linux).
14. Критерии корректности работы

Симуляция работает правильно, если:

    Полная энергия E остаётся примерно постоянной (дрейф не более 0.03 за 10000 шагов)

    Кинетическая и потенциальная энергии изменяются в противофазе (когда Ek растёт, Ep падает)

    Отсутствуют резкие скачки энергии

    Анимация показывает плавное движение частиц

P.S. (Теория)
1. Потенциал Леннарда-Джонса

U(r) = 4ε [ (σ/r)^12 - (σ/r)^6 ]

    r — расстояние между частицами

    ε = 1 — глубина потенциальной ямы

    σ = 1 — расстояние, на котором U(r) = 0

    r_min = 1.12σ — расстояние, на котором энергия минимальна

    U(r_min) = -ε = -1

При r → 0: отталкивание (U → +∞)
При r → ∞: притяжение (U → 0)
2. Кинетическая энергия

Ek = Σ (1/2) * m * (vx² + vy²)

    m = 1 — масса частицы

    Сумма по всем N частицам

3. Полная энергия

E = Ek + Ep

Ep = Σ U(r_ij) — сумма потенциалов по всем парам частиц

В замкнутой системе E должна сохраняться.
4. Алгоритм Верле

    a(t) = F(t) / m

    r(t+h) = r(t) + v(t)·h + 0.5·a(t)·h²

    a(t+h) = F(t+h) / m

    v(t+h) = v(t) + 0.5·(a(t) + a(t+h))·h

Ошибка метода: O(h²) для энергии.
5. Периодические граничные условия

Частица, вылетевшая за границу, появляется с противоположной стороны. Расстояние между частицами считается минимальным:

    если dx > L/2 → dx = dx - L

    если dx < -L/2 → dx = dx + L

То же для dy. Координаты могут выходить за [0, L], расстояния всегда правильные.
6. Три состояния

Газ:

    N = 10, L = 30, скорости 0.15

    E ≈ 0

    частицы хаотично летают, заполняют весь объём

Жидкость:

    N = 36, L = 12, скорости 0.06

    E ≈ -3 до -5

    частицы движутся, но держатся вместе

Твёрдое тело:

    N = 25, L = 12, скорости 0.0008

    E ≈ -20 до -30

    частицы колеблются около узлов решётки

7. Квадратная и треугольная решётки

    Квадратная решётка: у каждой частицы 4 соседа

    Треугольная решётка: у каждой частицы 6 соседей (более плотная упаковка)

Треугольная решётка энергетически выгоднее: Ep ниже.

8. Почему E немного меняется

Из-за численных ошибок:

    ошибка алгоритма O(h²)

    h = 0.0005 → ошибка ~0.03 за 10000 шагов

    дрейф отсутствует → симуляция корректна
